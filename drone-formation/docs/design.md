# GLB 三维点阵飞行

用户已确认：将 GLB 模型表面转换成 1000 个无人机光点，用 Three.js 演示飞行成形，支持视角旋转、缩放和重新播放。

独立静态应用，位于 web/drone-formation。Three.js 0.185.0 本地依赖；无需构建或上传服务器。GLTFLoader 支持内嵌资源的 GLB，配置本地 Draco / Meshopt 解码器。模型取默认姿态并烘焙世界变换，按三角形面积抽样，统一缩放、置中并抬高到地面上方。忽略退化三角形，无有效表面则报错并保留旧场景。最大文件 100 MB。

使用一组 1000 顶点的 THREE.Points 绘制光点。起点为地面阵列，终点为模型表面或示例球形。连续平滑插值仅用于可视化，无避障和真实飞控输出。控制包括上传、示例球形/螺旋/立方体、时长、参考模型、播放暂停、回到起点、进度与视角复位。尊重减少动态效果设置。

视觉：深蓝背景、青白光点、细线地面网格、左栏控制、右侧主场景、底部时间条。窄屏控制区域折为两列，场景占主要高度。

验证：采样数量、比例、退化网格、世界变换、动画端点和暂停；浏览器验证示例播放、上传真实生成的 GLB、无效文件保留场景、桌面与窄屏显示。用户模型尚未提供，使用测试 GLB 验证上传路径。
