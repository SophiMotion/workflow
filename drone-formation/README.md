# 点阵飞行

Three.js 实现的 1000 架无人机光点编队可视化，支持本地 GLB 上传、三维旋转缩放、播放暂停、进度拖动、重新编队和参考模型。

## 开启

推荐直接打开 SophiStudio 根目录的 `index.html`，点击「工作流 → 点阵飞行」，使用自动后台 http://127.0.0.1:4188/ 。首次设置时双击根目录的 `开启工作流自动启动.command`；以后登录 Mac 自动运行，无需终端或启动器确认。

也可在本目录运行 `npm start`，手动服务默认使用 http://127.0.0.1:4178 。无需 npm install，Three.js 0.185.0 和加载器已保存在 vendor 中。依赖遵守 vendor/LICENSE。

默认显示球形编队。点击“播放”从地面阵列起飞；上传 GLB 后自动生成 1000 点并开始飞行。可用 samples/torus-knot.glb 测试。重新编队返回起点，按播放开始。飞行时长支持 3–60 秒。拖动场景旋转，滚轮缩放，右上按钮复位视角。手机支持触摸。

## 模型支持

- 单文件、资源内嵌的 GLB，最大 100 MB、200 万三角形；支持 Draco 和 Meshopt。
- 以默认姿态处理网格、世界变换、蒙皮、形变和实例；按世界坐标三角形面积采样，统一缩放和抬高。
- 只采样表面，不填充体积；按比例采样不保证每个微小细节都有光点。
- 点色使用青蓝灯光，不提取原模型纹理；KTX2 纹理暂不支持。
- 模型在本机内存处理，不发送到服务器，不保存上传文件，刷新后需要重新选择。
- 动画为概念展示，没有最小间距约束、避碰、动力学或实际飞控输出。

## 验证

`npm test` 验证采样与动画核心。`node tests/create-sample.mjs` 重新生成合法/无效 GLB 测试文件。浏览器检查与视觉对照记录见 docs/verification.md。

## 从 SophiStudio 一键启动（macOS）

在 SophiStudio 的「工作流 → 内容与体验」点击「点阵飞行」，会在当前标签页直接打开 4188 端口的自动后台。该后台由 macOS 管理，退出后自动恢复。关闭自动后台、移动目录后的更新方法及日志位置见根目录的 `docs/local-services.md`。

原有 `sophistudio-drone://open` 启动器仍可单独使用，启动或复用的是 4178 端口手动服务；工作流入口不再依赖它。

`点阵飞行.app` 必须保留在本项目目录内，也可直接双击。服务独立于终端运行，日志在 `data/launcher.log`。启动器只接受固定打开动作，不执行网页传入的命令。端口被其他应用占用时会报错，不会终止其他服务。

换电脑或移动启动器后，可执行 `npm run build:launcher` 重新生成，然后用 macOS LaunchServices 注册该应用。Node.js 需已安装。直接双击 index.html 无法加载 Three.js 模块，请从启动器打开。
