先做一个节点，再扩展成项目库。

第一步
空间试验

在 Marble 生成“教学楼前的交接区”

使用本目录提示词，先做少量草稿。现有沙盘图适合模型式世界；若目标是身临其境，应补行人视点图、全景或三维布局。检查道路连通、视点与重复车辆。

第二步
网站接入

导出 SPZ，放入自己的浏览器场景

本页已预留 Spark 加载入口。先用低分辨率资产检查显示，再加入独立 GLB 车辆和碰撞代理。导入元数据校正尺度和地面，不从效果图推断工程尺寸。

第三步
行为验证

从任务回放，走向可复现的实验

浏览器轻交互可接 Rapier；交通组织研究另接 SUMO / CARLA；机器人传感与策略实验可评估 Isaac Sim。路网、语义、材质和动力学都需人工建模与校验。

第四步
平台沉淀

让未来案例共享同一份项目清单

Sophicar → 车辆版本；SophiStudio → 项目与审批；World API → 生成作业；仿真 worker → 运行记录。对象存储归档大文件，数据库保存关联，前端只读授权资源。

能生成空间，不代表已验证交通系统。

World Labs 可承担需要我们开发验证边界
环境外观、可探索空间、空间素材导出独立车辆、事件脚本、热点、任务 UI、案例管理静态环境不自带交通规则或车辆控制
SPZ / PLY 与碰撞或高质量网格尺度标定、道路与碰撞网格清理、坐标变换生成几何不等同于 CAD 或测绘真值
API 异步生成、资源查询、导出后端密钥、作业队列、预算、资产版本、失败恢复网页订阅与 API 额度分开计算
空间场景作为仿真输入的一部分物理、语义、传感器、路网与实验设计动画不能替代实物、交通或动力学测试

第一轮投入：以小样判断价值。

建议 6 个文本草稿 + 2 个标准世界作为最小比较集。按核查时 API 单价估算为 4,540 credits，约 US$3.632；API 最低充值为 US$5。若另外导出一次高质量网格，再加 US$2.80。费用不含托管、仿真算力和人工，实际用量与最新报价以控制台为准。

这是建议试验预算，尚未购买或生成。不要把预付余额当作硬性预算上限；生产系统需限制作业次数并在服务端记账。Atlas 已公开介绍，但本方案只依赖当前文档列出的 Marble API。
