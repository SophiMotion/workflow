# Sophi Worlds v1 设计说明

目标：评估浙大交通场景课程提案的项目表达，制作可交互的 `worldlabstestv1.html`，并为 Sophicar 与 SophiStudio 的案例和仿真提供共同入口。本轮没有 World Labs 账号、密钥或生成资产。

范围：一个本地静态工作台，包含场景展示、项目表达评估和深入开发三个页面状态。课程页面是提案，不能当作已开设课程或已完成学生成果。未来案例以“待接入”表示，不能编造项目数据。

视觉参考：`interface-concept.png`。白底，深绿 #205648，灰色正文，细边框；左侧项目库，中央校园图和回放条，右侧任务面板，底部三个过程步骤。正文 14–16px，标题 30px，导航 14px，控件 13–14px；圆角 6–10px。移动端改为纵向排列，不缩小文字。

必要差异：沿用已有的校园 AI 概念图，避免将 UI 设计图里的虚构建筑误作校园实景。新增项目/导入/导出为用户“未来案子和仿真都放进去”的必要入口。增加明确的未验证标签；3D 模式只在加载真实资产后显示内容。评估和开发为同一设计系统内的文字与表格视图。

实现：HTML 原生控件、内联样式与逻辑；本地存储项目元信息；JSON 导入导出。SVG 只画任务路径与标注，不假装生成 3D 世界。按需加载官方 Spark 2.3.0 和 Three.js 0.180.0，支持本地 SPZ/PLY 或 HTTPS SPZ 资源；资源失败时给出明确错误。密钥仅由 Python 工具从环境读取。

验证：浏览器检查桌面和手机布局、任务选择、阻挡/解除、回放拖动、项目搜索筛选、新增及 JSON 导入导出、接入弹窗、错误资源路径；API 工具做离线校验。没有付费 World API 调用，课程真实 SPZ、硬件与仿真验证保留为未验证。
