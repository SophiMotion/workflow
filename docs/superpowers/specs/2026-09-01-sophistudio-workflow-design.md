# SophiStudio · SophiMotion 研发工作流首页设计

日期：2026-09-01

## 目标

在 `sophistudio` 根目录新增一个自包含的 `index.html`，统一说明、组织和启动各子项目。首页是 SophiMotion 的研发工作台，不改动各子项目内部实现，也不要求通过 npm 启动后台或开发服务器。

## 技术方案

- 采用单文件静态页面：HTML、CSS、JavaScript 全部放在根目录 `index.html`。
- 不增加 package.json、npm 依赖、构建命令或后台服务。
- 所有模块入口使用相对路径；有构建产物的前端应用优先打开其静态 `dist/index.html`。
- 可用模块在新标签页打开，使研发工作台保持可见。
- 尚无可运行入口的模块显示“规划中”，不提供无效链接。
- 页面应能从文件系统直接打开；同时兼容任意普通静态文件服务器。

## 信息架构

### 知识与研究（Google Blue）

1. `unit`：整个项目团队及能力介绍。
2. `online-vault`：知识库管理与检索，作为后续 RAG 调试基础。
3. `paper`：科研课题建议器。基于脱敏项目资料和蒸馏论文，输出候选课题、研究假设、实验变量、设备与数据需求、候选创新点、文献依据、可行性与风险。

### 工程研发（Google Green）

1. `sophicarv2`：底盘开发的设计与仿真基础。
2. `cfd`：空气动力学仿真，是 SophiCar V2 的仿真分支。
3. `sophicar-stl-f3d`：STL 数据处理与分析，并转换为 Fusion 360 可继续编辑的 F3D 原始数据。
4. `sophicar-formate`：F3D 数据转换与发布，当前定义为从 F3D 导出 STL 和 URDF。
5. `stlquote`：工程模型分析与报价系统。

工程流程的主线为 `sophicarv2 → sophicar-stl-f3d → sophicar-formate → stlquote`，`cfd` 从 `sophicarv2` 分支出来并回馈设计判断。

### 内容与体验（Google Red）

1. `media`：自媒体视频生成器。
2. `sound`：声音模拟器，作为后续开发预留。

## 模块入口与状态

| 模块 | 状态 | 静态入口 |
| --- | --- | --- |
| unit | 可用 | `unit/index.html` |
| online-vault | 可用 | `online-vault/index.html` |
| sophicarv2 | 可用 | `sophicarv2/index.html` |
| cfd | 可用 | `cfd/dist/index.html` |

状态由当前目录内容确定。首页本身不伪造功能，也不把开发源码入口误标为可直接使用的入口。

## 页面设计

### 视觉系统

- 背景使用纯白，正文使用接近 Google Material 的深灰，边界使用浅灰。
- 三条工作流分别使用 Google Blue、Google Green、Google Red。
- Google Yellow 只用于少量进度、提示和连接节点，不代表第四类工作流。
- 字体优先使用 `Google Sans` 风格的系统字体栈，并以 `Noto Sans SC`、系统无衬线字体回退，避免页面可用性依赖远程字体。
- 形态保持克制：清晰的轨道、节点、线条和留白，不使用密集的通用卡片墙。

### 页面结构

1. 顶部品牌栏：SophiStudio 标识、工作台名称和简短说明。
2. 首屏概览：标题“SophiMotion 研发工作流”、可用模块数量及简洁的整体进度表达。
3. 三条流程轨道：每条轨道含类别说明、模块节点、职责、状态和操作。
4. 工程轨道单独表现 CFD 分支关系。
5. 页脚说明该页面是统一静态入口，并展示最后更新时间。

## 交互规则

- 可用模块显示“打开模块”，点击后通过新标签页进入静态入口。
- 规划模块显示“规划中”，按钮不可点击，并保留完整功能描述。
- hover 只使用轻微位移、边框和阴影反馈；键盘焦点必须清晰可见。
- 页面载入时可使用轻量分段出现动画；系统开启减少动态效果时禁用动画。
- 桌面端展示横向研发轨道；窄屏下转换为纵向时间线，不产生横向滚动。
- 页面不包含需要后端支持的搜索、账户、同步或伪造数据控件。

## 异常与兼容处理

- 仅向已确认存在的静态入口生成链接。
- 规划模块不生成 `href`，避免打开空目录或 404 页面。
- 外部字体、图标或脚本不是首页运行的必要条件；图标使用内联 SVG。
- 使用语义化 HTML、可读的按钮标签、ARIA 状态和足够的颜色对比度；状态不只依靠颜色表达。

## 验证标准

- 直接打开根目录 `index.html` 时，页面可完整显示且无必需资源缺失。
- 七个可用模块的入口路径正确，并能直接打开对应静态页面或构建产物。
- 三个规划模块无法误触进入空页面。
- 桌面和手机尺寸下均无内容裁切、按钮重叠或横向溢出。
- 三类工作流颜色严格对应：蓝色知识与研究、绿色工程研发、红色内容与体验。
- 页面无需执行 npm、无需本地后台进程即可使用。

## 范围边界

本次只创建统一首页，不实现 `paper`、`sound`、`sophicar-stl-f3d` 的内部功能，也不重构现有七个可用子项目。
