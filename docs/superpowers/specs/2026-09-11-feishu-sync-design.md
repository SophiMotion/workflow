# 飞书知识库本地同步

用户要求：工作流入口打开 `feishu.html`；初始化下载所选知识库为 Markdown；自动化持续拉取更新；知识库配置可在页面维护。

采用静态页面与 Python 3.9+ 标准库本地服务。服务只监听 127.0.0.1:8769。页面从 file:// 打开时连接该服务，也可以由服务托管。凭据仅在后端读取 `.env`（兼容上级 2026/.env），页面配置写入项目 `config/feishu.env`，不进入 Git。

初始化及增量同步均完整分页遍历授权知识空间和子节点。支持新版文档富文本转 Markdown、图片附件下载、电子表格和多维表格转 Markdown 表格。旧版文档导出纯文本并明确标记格式降级。暂不支持的类型保留来源说明及结构数据并计入警告，不宣称完整转换。

版本模型使用 SHA-256 基线、不可变内容快照、逐次变更记录与 unified diff，实现 clone / pull / status / conflict 概念，不操作用户项目 Git 仓库。目录保留知识库和节点层级；文件名含稳定标识防重名。本地修改与云端修改同时存在时保存待处理远端版本，禁止静默覆盖。页面可以查看差异并选择保留本地或采用远端。

云端节点不可见（删除或权限变更）只标记并保留本地文件，不自动删除。单篇失败不阻断其他文件；遍历失败不执行缺失节点判定。错误、降级、冲突和成功分别显示。增量比较依赖节点更新时间与内容校验；表格每轮读取，避免遗漏独立更新。

自动化由服务内线程执行，配置和开关持久化，重启恢复；页面关闭后继续，服务停止或电脑休眠期间暂停。提供 macOS 启动脚本；此版本不安装系统登录启动任务。

安全：限定 HTTP Host / Origin；写操作要求自定义请求头与服务会话 nonce；配置和状态文件不通过静态路由公开；路径限制在模块目录，拒绝符号链接越界；请求限制、超时和重试；不同步上传、不向他人发消息。

验证：离线模拟飞书响应测试分页、格式转换、首次下载、无变化、更新、重命名、冲突、权限错误、缺失节点保护、自动化持久化及 API 安全；浏览器测试工作流跳转、配置、运行状态、空状态、桌面及手机布局。实际飞书权限和全量数据联调以可用凭据和授权范围为准。
