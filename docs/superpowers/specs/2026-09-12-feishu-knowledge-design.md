# 飞书本地知识库：阅读与双模型问答

用户希望直接阅读已下载文档，并基于知识库获得专业建议：OpenAI 按国际视角分析、DeepSeek 按国内视角分析，最后由 DeepSeek 综合。

## 范围与流程

- 在现有 feishu.html 中增加问答区域和正文阅读对话框，保留同步、冲突及历史。
- 文档标题打开当前本地 Markdown，支持代码、表格、图片及附件；通过受保护 API 读取，禁止直接公开 vault。
- 本地全文索引按段落切块，保留文档、行号、版本指纹和导出提示。按选择的知识库检索，默认两个已同步知识库。没有相关资料时明确提示，不伪造依据。
- 使用固定版本的官方 DeepSeek Harness 核心 LLM 服务与 DeepSeek 适配器，在独立 Node 子进程内运行知识问答插件；不加载文件编辑、Shell、网页操作工具。
- 相同证据分别交给国际分析与国内分析，再由 DeepSeek 综合。页面可查看三份答案、模型名称、调用状态、耗时和引用。
- 国际/国内是分析任务设定，并非对模型能力或中立性的保证。结论区分知识库事实、模型推断和待验证的外部事实；不同意见保留。
- 问答只发送检索命中的片段和问题至已配置的两个官方 API；知识库全文及凭据不进入前端，也不发送给其他主机。OpenAI 回答会作为综合材料发送给 DeepSeek。
- 知识库内容与模型回复均作为不可信资料，不作为执行指令。引用检查只能校验来源是否存在，不能自动证明结论正确。

## 配置与生命周期

密钥写入独立 config/feishu-ai.env，0600 且忽略 Git。允许明确导入现有 ~/.dsh/.credentials.yaml 中的命名模型密钥；页面只显示是否配置，绝不回显密钥。模型名可维护。缺少某一路凭据或请求失败时明确展示未完成，不用另一个模型冒充。

问答任务后台运行，单次超时有上限，支持停止。浏览器刷新可恢复最近结果；服务重启将未完成任务标记为中断。同步后的下一次问答更新本地索引。聊天历史及证据保存在私有 .state，采用原子写入。

## 验收

可打开真实正文并下载附件；路径穿越、私有文件访问、Markdown XSS 均被阻止。中文/英文查询能返回相关片段；无依据不会假装有引用。实际双模型调用成功后能生成带可点击来源的综合建议。某一路失败、取消、重启、配置缺失不显示假成功。保留现有同步行为并运行相应回归测试。
