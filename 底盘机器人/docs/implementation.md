# SkateChassis 工作台

## 目标与视觉
SophiStudio 内的独立工程工作台；可由工程研发工作流进入。参考用户的管状双臂四轮机器人，使用白色面板、浅灰三维画布、石墨文字与黄绿色选中态。Geist 风格几何字体、克制圆角、清晰层级与 GSAP 切换动效。界面参考 Downloads/SKILL.md 的视觉原则；营销页 AIDA 和滚动锁定不适用于常驻工程画布。

## 同源数据
共享配置驱动模型、零件数量、工程估算、BOM、报价、PRD 和导出。Node HTTP 后端持久化项目，能力链接访问，字段比较交换防止覆盖并发编辑。支持共享链接、署名、评论、解决评论、版本快照、冻结 PRD 与重新开启变更。静态部署降级为明确标记的本地模式。

## 价格与报价
未获取到可核实天猫 SKU 报价，所有初始价格为种子估算。核价必须填写具体天猫商品 URL、规格、店铺、含税价格、税率与核价日期，统一换算到未税成本后报价。过期价格自动回到待复核。明确显示估算状态，不把搜索链接当作商品报价证据。报价规则可调并随项目保存，NRE 一次计入订单。

## 工程导出
统一米制装配描述生成标准 URDF，含 link、joint、惯量与碰撞体，附 ROS 2 description 包和展示 launch。Fusion 脚本生成组件、受用户参数驱动的草图尺寸及拉伸特征、关节，再使用官方 API 导出真实 F3D；网页交付脚本包而不伪造原生 F3D。几何为参数化概念模型，非图片逆向的制造级模型。需要 Fusion 环境实机验证。

## PRD
覆盖 PDF 的全部 13 章，保留文档身份、项目概况、需求基线、接口、RACI、里程碑和验收、资源与 BOM、商务、CR、安全和权属、复盘、启动确认及激励。PDF 中开篇第 11 节变更的交叉引用与实际第 9 节不一致，页面按实际章节标题组织。

## 验证
验证金额税基和数量、配置边界、URDF 关节树和惯量、Fusion 脚本语法、协作并发与鉴权、页面交互和响应式、导出 ZIP、生产构建与 SophiStudio 入口。
