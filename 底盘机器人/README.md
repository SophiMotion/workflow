# SkateChassis · SophiStudio

参数化机器人设计工作台，参考用户提供的 SkateChassis 效果图、UI 风格说明和 13 章 Project Kickoff PRD 模板。

## 在线静态版

打开 **https://sophimotion.github.io/SkateChassis/** 即可使用，无需安装 Node.js 或启动后端。

静态版支持参数设计、三维预览、外观装配、BOM、报价、PRD、版本快照及工程文件下载。项目保存在当前浏览器的 localStorage 中；外壳模型仍是临时会话，离开前请下载备份。静态版不提供跨设备协作或自动唤起 Fusion；下载的 Fusion 配置可在本机插件中导入。

部署环境由静态构建模式与 GitHub Pages 域名自动识别，静态版不会请求项目 API。SophiStudio 扩展工具需要本地运行环境。

```sh
# Node.js 22.12+，推荐 Node.js 22 LTS
npm ci
npm run build:static
npm run preview:static
```

本地预览地址为 **http://127.0.0.1:4175**。`dist-static/` 是完整静态站点，可放到任意 HTTP(S) 静态服务器的根目录或子目录；资源使用相对路径。请通过 HTTP(S) 打开页面，直接双击 HTML 不支持交互工作台。

推送 `main` 后，`.github/workflows/deploy-pages.yml` 自动安装锁定依赖、运行 Node / Python 测试、构建并发布 GitHub Pages。仓库 Settings → Pages → Source 使用 **GitHub Actions**。`dist/` 仍供本地协作服务使用，静态构建不覆盖它。

## 预览和运行

**日常使用，无需终端：** 双击项目中的 `SkateChassis 工作台.app`。它会在后台启动本地服务，确认就绪后打开浏览器；已有服务时直接复用。

也可以双击 `打开工作台.html`，点击“启动工作台”调用同一启动器。浏览器首次可能询问是否允许打开本机应用；若没有反应，先在访达中打开一次 `.app`。HTML 本身不执行 Node 命令。

Codex 内置预览在本次验证中拦截了 `file://` 和自定义协议启动链接，因此其中的 HTML 按钮联动尚未完成实测；原生启动器已实际启动后台服务。可直接在访达中双击 `.app` 使用。

关闭网页不会停止后台服务。重启电脑后，再次双击启动器即可；没有设置开机自启。
请保留 `.app` 在当前项目目录，可以拖入 Dock 或创建替身。启动错误会以系统对话框提示；服务日志保存在 `data/workstation.log`。

**开发者启动：** 仍可双击 `启动工作台.command`，或在本目录运行：

```sh
npm install
npm run dev
```

打开 **http://127.0.0.1:4173**。直接打开 `index.html` 会显示启动入口，交互工作台仍由本机服务提供。

改动网页后运行 `npm run build` 更新启动器使用的页面。`npm run build:launcher` 会生成 macOS `.app` 和根目录 HTML 入口；需要当前机器已安装 Node.js 和 Xcode Command Line Tools。启动器保存当前 Node 路径，移动到其他电脑后应重新生成。
开发源文件是 `scripts/launcher/Launcher.swift`、`scripts/launch-service.mjs` 和 `public/打开工作台.html`。

SophiStudio 主页面通过 **http://127.0.0.1:4173/studio/#/workflow** 访问；其「工程研发」包含本工作台入口。返回链接和工具箱可打开本地 SophiCAD Bridge、STL Quote、PRD / SOW、SophiCar V2 和 CFD。

## 可用功能

- 结构、动力、电控、传感选型；WebGL 参数模型、旋转、缩放、正 / 顶视、尺寸标记、分解和线框；原始效果图切换。
- 同一配置驱动 BOM 数量、制造规格、成本与报价。变更非标件尺寸后，其旧核价不会自动用于新规格。
- 天猫手工核价：商品详情链接、实际 SKU、店铺、含税单价、进项税率和日期。初始值全部为**估算**，不是抓取的天猫实时价格；7 天后提示复核。自动抓价接口尚未接入。
- 报价规则可调，按目标毛利率计算售价；CSV BOM、可打印报价单和 PRD、JSON 项目快照、一键工程 ZIP。
- PRD 覆盖模板全部 13 章；章节编辑、结构化需求、负责人 / 日期 / 指标、启动清单、讨论、评论解决、评审与冻结、变更重开、版本快照。
- 真实项目服务：每 2.5 秒同步，字段比较交换检测并发冲突，项目 JSON 原子落盘。分享链接携带项目访问能力；知晓链接即可编辑。编辑者姓名仅为署名，不是账号认证。
- URDF 含 SI 单位、link / joint、限制、惯量和碰撞体；ROS 2 ZIP 附 description package、launch 和 RViz 配置。
- Fusion 导出下载当前 `.fusion.json` 配置，同时通过本机服务唤起 Fusion。`SkateChassis20260906` 插件接收同一配置、打开面板，提供“生成新模型”和“保存 F3D”。完整工程包内也包含这份配置。**浏览器不会直接生成原生 F3D。**

## 混元 GLB 外观装配

在「参数设计」点击「导入外壳」，或打开「外观装配」页，直接拖入混元生成的 `.glb`。模型在浏览器内处理，不上传到混元或其他服务；「先试用演示外壳」提供程序化样件，方便先熟悉操作。

1. 导入后，根据立柱高度初步缩放和落位；用整体尺寸、方向与位置控制对齐机器人。
2. 选择甲片，用 X / Y / Z 切面预览后「拆为两块甲片」。这会生成实际网格，保留 UV、贴图与材质；可重复切割、改名、隐藏或删除。
3. 如需减小模型，可展开「手动减面（可选）」对所选部件操作；默认保留完整面数。切割与减面在后台线程执行，撤销记录按下述内存预算保留。
4. 选择「绑定连杆」，将硬甲关联到立柱或手臂连杆；「移到连杆中心」可帮助初步定位，再调整尺寸与偏移。绑定时保留当前姿态，关节角度预览用于观察是否穿插；继续编辑前先回到零位。
5. 外壳是**临时会话**：刷新、离开「外观装配」或切换浏览器标签，会清空当前模型、原始文件缓冲区与撤销记录，释放几何和贴图，停止后台切分任务。再次进入需重新导入，不自动恢复大模型。启动时直接删除当前工程的旧 IndexedDB 外壳草稿；配置、BOM、PRD 和版本记录不受影响。
6. 「保存外壳文件」下载包含所有部件（含隐藏部件）、原始尺寸贴图和绑定信息的 GLB 备份，不再向浏览器写入大模型。离开前需要保留编辑时使用此按钮；再次导入备份可继续编辑。
7. 「导出 GLB」导出可见外壳，默认保留原始贴图尺寸，也可手动选择 1024 / 2048 / 4096；重新导入本工作台可以继续编辑和恢复绑定。导出不包含底盘骨架，其他软件不一定识别本工作台的连杆元数据。

支持内嵌贴图的静态 GLB，以及 Draco / Meshopt 压缩网格。导入和保存限 512 MB、500 万三角面与 250 个部件；超出时给出提示并保留当前编辑。默认效果优先，不自动减面或缩小贴图；「手动减面」仅在主动执行时生效。实际可处理规模取决于设备内存和显存。暂不接受外链资源、KTX2 贴图、蒙皮、变形目标或实例化模型。

大模型切分在后台线程中保留索引并共享未切割顶点，显示处理进度和等待时间。撤销最多保留 10 步，几何缓冲区超过约 384 MB 时优先释放较旧的记录，并至少保留最近一步；贴图不计入这个撤销预算。

这是外观适配工具：切口暂未封闭，不会自动生成内腔、壁厚或安装孔；手动切割也不等于 AI 自动识别肩甲、胸甲等结构。关节预览尚不计算碰撞、运动间隙或制造可行性。外壳独立于共享工程、BOM、PRD 和版本快照，不随共享链接同步；只有已下载的外壳文件会在离开页面后保留。

## Fusion 插件

插件存放于 `../autodesk/SkateChassis20260906/`，主文件为 `SkateChassis20260906.py`。
首次在 Fusion“实用工具 → 脚本和附加模块”中从设备添加整个文件夹，并启用运行和自动加载。
网页工程导出中的“下载配置并打开 Fusion”完成两件事：下载当前配置、请求本机 Fusion 插件打开。
只有收到插件的回执后，页面才显示“插件已接收配置”。未连接时仍能下载并在插件内手工导入。

联动限本机 macOS。请求必须来自本机 HTTP 页面；局域网其他设备不会触发服务器电脑的 Fusion。
原生插件通过 `bridge.json` 指定目录读取请求，配置只包含当前参数和概念几何，不包含 PRD、采购价格或项目访问凭据。
插件生成新文档，不将新配置强行合并到用户手工修改过的现有设计。

开发时，`public/fusion/SkateChassis20260906/` 为插件源文件；运行 `node scripts/install-fusion-addin.mjs` 同步到安装目录。
安装脚本在覆盖不同内容前保存备份。修改代码后，需要在 Fusion 停止并重新运行插件。

## 报价规则

1. 商品未税单价 = 含税原价 ÷ (1 + 进项税率)，先四舍五入至分；物料成本 = Σ 未税单价 × 单台数量。
2. 损耗 = 物料 × 损耗率。
3. 管理成本 = (物料 + 损耗 + 装配 + 测试) × 管理成本率。
4. 单台制造成本 = 物料 + 损耗 + 装配 + 测试 + 管理成本。
5. 单台未税售价 = 制造成本 ÷ (1 − 目标毛利率)。
6. 订单未税价 = 单台未税售价 × 台数 × (1 − 折扣率) + NRE + 物流。NRE / 物流只计一次。
7. 含税订单 = 订单未税价 + 四舍五入至分的销项税额。

所有规则随版本保存。默认输入：损耗 3%、装配 800 元 / 台、测试 400 元 / 台、管理 8%、毛利 20%、销项税 13%、NRE 3000 元 / 单、物流 200 元 / 单、折扣 0%。这是可调整的报价模型，不代表天猫商品成交价或税务结论。

## 团队与部署

```sh
# 局域网内使用；成员以本机局域网 IP 打开后复制共享链接
HOST=0.0.0.0 npm run dev
# 生产构建与服务
npm run build
HOST=0.0.0.0 npm start
```

生产环境需要持久化 `data/`（可用 `DATA_DIR` 指定），并在现有 SophiStudio 登录网关后代理 `/api/skate/`。共享链接不包含登录系统身份；还未接入飞书 SSO、角色权限或云数据库。

`dist/` 可嵌入 SophiStudio 子路径，资源使用相对 URL。同源 `/api/skate/` 可用时启用协作；纯静态托管时明确降级为 localStorage 本地编辑。`/studio/` 为随附 Node 服务上的现有工具静态挂载。若部署在另一站点，需要将该挂载映射到实际 SophiStudio 根目录。

## 工程边界

- 效果图没有精确尺寸或 CAD 数据，当前是由输入参数构建的概念装配。加工孔位、公差、线束、驱动协议、执行器扭矩和装配干涉需继续详细设计。
- 续航与质量是估算。URDF 惯量按简化几何与估算质量计算；轮轴沿 Y。麦克纳姆轮的碰撞体为圆柱外包络，不含滚子接触模型。没有伪造 Gazebo 或硬件控制驱动。
- Fusion 以受参数驱动的刚性定位关节维护布局；完整运动学链在 URDF 中描述。Python 已做语法检查；当前尚未在 Autodesk Fusion 实机运行、导出和重新打开验收。
- 天猫自动价格接口、制造级零件库、SSO 身份和公网协作后端需按真实服务接入；GitHub Pages 仅托管静态工作台。
- PRD 模板交叉引用中有章节号不一致，页面按实际 13 个章节标题组织。
