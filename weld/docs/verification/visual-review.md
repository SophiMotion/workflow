# 视觉与交互复核

设计输入：用户参考截图、内置 Image Gen 生成的 `../design-concept.png`。交付基线为 `../design.md`，用户随后确认“先完成可交互演示版”。

使用 Codex IAB 实际加载与操作。REA 另行捕获独立 Chrome 场景，不是 IAB 失败后的替代。桌面 1600×1000 与手机 390×844 已检查。主任务使用 `view_image` 同轮查看了设计概念、最终桌面、分析页与手机截图。

| 检查点 | 结果与设计取舍 |
|---|---|
| 信息布局 | 保留左模型树、中三维场景、右参数、下时序与播放栏，未改成展示型首页。 |
| 色彩 | 白色界面、冷浅灰画布、橙色操作强调；无照片蒙版。 |
| 字体与控件 | 全部为原生可选文字，统一系统字体、紧凑字号、数字等宽；触达按钮有名称与焦点样式。 |
| 场景 | 程序化几何取代概念中写实场景，以满足旋转、轨迹运动与场量着色；不宣称与真实 ABB 几何相同。 |
| 时序 | 4 道真实本地数据驱动的行，按选择顺序和长度/速度计算；运行进度同步。 |
| 参数 | 输入框、选择框、有效线能量联动；补充 input 事件修复仅依赖 change 的自动化输入提交问题。 |
| 窄屏 | 树与参数为抽屉；增加参数面板内部关闭按钮；按视口长宽比调整相机视场以展示完整单元。 |
| 云图 | 修复 material.needsUpdate 后颜色真实绘制；明确为示意分布。 |
| 运行状态 | 结果、坐标系和外部连接来源均有说明，不把演示估算标成真实软件求解。 |

首屏文案对照：主要导航“工作站 / 焊接策略 / 仿真分析”、项目结构、工艺参数、保存、运行、时序与状态均保留。增加“导入”“加工策略”“导出工艺包”和实际计算时长是满足数据交换和操作要求的有意扩展。未声称完全复刻概念像素；机械细节、工具栏密度及字号以交互演示实现为准。
