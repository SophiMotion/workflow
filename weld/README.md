# SOPHI WELD · 焊接仿真工作台

参考提供的 RobotStudio 截图构建的可交互演示项目，整合机器人工作站、焊接策略和分析结果工作流。主交付文件为 **weld.html**，内联构建产物，内置样式、程序、图标与 Three.js，运行不依赖 CDN。

## 打开

直接用 Chrome / Edge / Safari 打开 `weld.html`，或在此目录运行：

```sh
npm start
```

访问 `http://127.0.0.1:8765/weld.html`。浏览器需支持 WebGL；不支持时仍可编辑工艺与处理结果数据。

## 默认：白车身 ABB 三工位流水线

- 默认加载程序化钣金白车身：门槛、A/B/C 柱、开放门洞、顶边梁、轮罩、地板与横梁；三套定位夹具、输送轨道、控制柜和 ABB IRB 6700-235/2.65 六轴机器人。
- OP10 前段定位、OP20 侧围补焊、OP30 后段补焊，每站四点，共 W01–W12。三站同时加工不同车身，全部回待机位并松夹后统一移载。
- 三维机器人、铜电极开合、夹紧机构、焊点压痕和并行时序共用确定性时钟；支持循环、暂停、任意拖动、全线视角和单站聚焦。点焊采用绕过翻边的侧向进退枪，通电 / 保压时 TCP 保持不动。
- 默认三站作业分别为 **24.6 / 28.1 / 23.6 s**。稳态出车间隔为 **max(三站作业) + 4 s 公共移载 = 32.1 s/台**，维护摊销 0.24 s/台后为 32.34 s/台，100% 有效比例下估算 111.3 JPH。单车经过三站驻留约 96.3 s，不能与出车间隔混淆。
- 每站空行程可分别设置，工艺参数全线共用；瓶颈、等线、节拍和产能随输入重算。维护假设三站同步停线，使用最长工位维护时间。上游供件、下游搬运和真实 PLC 逻辑不在模型中。
- 在顶部场景下拉框切换到单机械臂焊接，可继续使用原有 MAG / 脉冲 / TIG / 激光和搭接板点焊教学；场景切换保留本次会话中的两套配置。
- 新项目存储键为 `sophi-weld-project-v2`，旧版存储保留；已导出的旧 JSON 仍可导入。新增 `examples/biw-line-project.json` 可恢复白车身默认参数。
- 机械臂模型可选「ABB IRB 6700 · 真实六轴网格」或「原版机械臂 · 示意机构」。单工作站教学场景也保留。
- 新模型使用 ROS-Industrial 的原生视觉 / 碰撞 STL 与 URDF（固定 revision `45f4769`，Apache-2.0）；来源和范围见 `assets/abb-irb6700/NOTICE.md`。模型完全嵌入离线 HTML，无运行时网络依赖。
- 六轴 FK / IK 驱动法兰和焊枪。空走使用关节插补，进出焊点使用笛卡尔目标逆解；显示 J1–J6、行程、速度、TCP / 姿态残差和腕部奇异邻域。参数时间仍是手动估算，没有 ABB 控制器或动态负载验证。
- 三站在相同时间检查原生连杆碰撞网格与枪臂、BIW、活动夹具、输送线、围栏、控制柜，以及已配置的非相邻自碰撞和跨站机器人。全路径检查步长 ≤ 0.05s 并包含阶段边界；排除相邻机械连接、法兰连接、电极接触区，不包含柔性线缆或连续碰撞证明。
- 检出干涉 / 不可达 / 越限时暂停播放；工程校核中的碰撞记录可点击定位。隐藏模型不会关闭几何校核。
- OP10 / ABB 改为跟随视角的清晰 DOM 标记，移除地面与焊点旁的贴纸。新增「焊点特写」，收起关节面板并隐藏空间文字，避免 OP20 焊接被遮挡。

源文件：`src/line-data.js` 工位与点位；`src/line-motion.js` 确定性动作与简化检查；`src/abb-rig.js` 原版外观；`src/abb-kinematics.js` 六轴运动学；`src/abb-six-axis.js` 原生网格与焊枪；`src/mesh-collision.js` BVH 检查；`src/biw-scene.js` 白车身、夹具、输送与三站场景；`src/line-ui.js` 并行时序与节拍解释。ABB 外观 / 应用参考：[官方点焊功能包](https://campaign.abb.com/fabtech2019)。

快速体验：点击“运行仿真”观察全线循环；点 OP10 / OP20 / OP30 聚焦工位；点底部任意动作跳到闭枪、通电、保压或公共移载；右侧“节拍口径与辅助时间”可调整各站移动时间。

## 钣金接触特写与本地控制器模拟（2026-10-15）

- 默认为薄板侧围、开口轮拱、半幅内轮罩、冲压地板与顶板。轮拱属于车身钣金，未安装轮胎。车身是程序化教学模型，不是 OEM CAD。
- 右侧“车身与焊枪”保留原版骨架／焊枪；机械臂选择仍独立保留。精细 C 型伺服枪支持每层 1–3 mm 板厚，后电极与两层板背面贴合，前电极随行程和微小压痕闭合；原版可继续查看 X 型示意。
- 点“电极特写”进入局部隔离剖切，按闭枪、加压、通电、保压、开枪、压痕逐阶段查看；0.5× 慢放仅播放当前焊点。截面显示实际板厚，电流／压力读数是选定阶段快照。压痕深度／颜色是确定性的教学形貌，不是材料接触或焊核求解。
- 页面右上方或流水线工具条“控制台”打开 RobotStudio 风格的本地模拟界面。支持连接、上电、自动启停、手动阶段单步、故障复位、三个任务的关节／I/O、工具坐标记录、非执行 RAPID 预览、事件日志。
- 控制器与三站共用时钟。连接后运行需电机 ON 和自动模式；手动模式可按阶段单步；干涉／越限触发故障。暂停、下电或断开后模拟通电命令归零；三维特写保留所选时刻快照。
- 本机没有用户提供的 RobotStudio 安装或控制器地址；本界面明确标为“本地模拟”，不是 ABB 原版界面、RobotWare 或 ABB Virtual Controller。REA 用于验证本网页的实际交互，没有声称逆向原生 RobotStudio。
- 金属环境反射和按需绘制改善薄板／电极显示与暂停时性能。局部隔离仅影响显示，三站几何检查仍使用完整场景。

源文件：`src/sheet-body.js`、`src/spot-contact.js`、`src/servo-spot-gun.js`、`src/controller-sim.js`、`src/studio-ui.js`、`src/studio.css`。自动验证覆盖 `tests/spot-contact.test.mjs`、`tests/controller-sim.test.mjs` 和 `tests/manual-scene.test.mjs`。

## 八步工程流程升级

- 顶部提供数据、工具、任务、路径、干涉、节拍、可达性与交付八步说明，参数旁的问号可直接解释当前设置，说明中可定位到相关操作。
- 焊接方式支持电阻点焊、MAG、脉冲 MAG、TIG、激光焊。白车身点焊使用三站 12 点；单站点焊使用搭接薄板、C / X 枪示意和四个定点任务；激光焊独立配置功率、扫描速度和离焦记录。点焊和激光焊不显示电弧。
- 可以选择均匀成形、热输入不足、过热三个教学结果场景，联动三维形貌与演示温度曲线。这是主动选择的示例，不是质量预测；切换工况会清除旧计算和导入结果。
- `src/engineering.js` 统一动作阶段与节拍：单站 MAG 工位周期 176.00 s，搭接板点焊周期 31.40 s。它们均为一个机器人串行执行四任务的估算，已包含上下件、夹紧、移动和等待。默认维护摊销为 12 / 50 = 0.24 s/台。
- 60 JPH 对应理论周期 60 s；可用预算 = 理论周期 × 有效生产比例。焊后冷却观察独立于生产周期，不因观察时长增加而降低估算产能。白车身模式采用三站并行的简化调度；真实 PLC 互锁及控制器节拍尚未求解。
- 节拍分解可点击每个阶段定位播放，点焊明确区分闭枪、加压、通电、保压、开枪；结果曲线可切换温度、应力和位移。
- 工程校核可采样整条路径（运动阶段间隔不超过 0.2 s），检查示意臂展、简化碰撞与设定间隙；近碰不会提前掩盖同一包络的碰撞。点焊的正常电极接触不纳入禁止碰撞。
- 工具 / 附件质量支持静态质量筛查。TCP、重心、惯量、离焦量明确标为记录或待外部验证；白车身模式的开口行程会改变电极开度；几何 TCP 使用模型固定偏移，输入的 TCP / 负载记录不改变该偏移。
- 项目 JSON 向后兼容旧版本。中立工艺包升级为 `sophi-weld-exchange/2`，包含阶段、单位、节拍和未校核项；HTML 报告按焊接方式使用对应参数。外部 CSV 保留来源且可查看完整时间范围，空间云图仍为当前教学模型。

新增源文件：`src/engineering.js`（工程数据与时序）、`src/workflow-ui.js`（步骤说明和工程面板）、`src/report.js`（带来源和能力边界的报告）。

## 演示边界

RobotStudio 与 Simufact Welding 当前均未连接。REA 没有接收到这两款软件的程序或工程，因此未对它们进行原生逆向分析。ABB 六轴模式使用来源明确的连杆网格与轴定义，包含 FK / IK、关节行程 / 速度及网格碰撞检查；原版保留两连杆示意机构。三站 BIW、枪体和夹具仍为教学几何，未校核真实控制器、加速度、动态负载、柔性线缆、全部奇异类型或严格连续碰撞。温度、应力、位移为简化示意估算，材料仅影响少量示意系数，不是材料数据库。热循环使用指数冷却，纹理与风险阈值为未标定的教学规则；云图不是有限元热传导解。几何比例与焊缝长度属于示意映射，焊道预览不等于实测熔深或合格焊脚。导入的时程图属于真实读取的数据，但空间云图仍为示意。正式工艺需要真实 CAD、热源标定、材料数据库和原生求解器验证。

## 同屏控制台、点动与极氪 001 外形参考

顶部项目名称下拉菜单可直接切换“单机械臂焊接”（原 MAG 金属板 / 支架项目）和 ABB 三工位。“车身模型”保留极氪 001 外形参考、上一版钣金白车身、原版骨架；右侧继续保留原版示意机械臂。

“同屏控制台”停靠在三维视口旁，手机上为上下布局。六轴点动顺序：连接模拟 → 电机上电 → 手动模式 → J1–J6 的 ± 按钮，每次 0.1°、1° 或 5°。使用真实关节 FK，每 ≤0.5° 检查全线网格，碰撞或限位时回到原姿态。手动开 / 合枪与接触反馈同步；手动模式不触发焊接。点击“返回程序姿态”再运行自动程序。该返回操作是网页姿态快照切换，不是实际回位轨迹。

TCP 与工件坐标以各工位 `controlFrames` 保存。值为相对名义装配的六维标定偏移（mm / degree），旋转为固定轴 Rz × Ry × Rx。TCP 局部 X 为焊枪切向、Y 为电极法向；工位 X 沿线、Y 向上、Z 朝机器人。工件实物保持固定，工件坐标移动程序目标；工具偏移参与 IK。手动点动时保持关节角，仅重算标定后的 TCP。标定失配会阻止通电和焊点完成 / 压痕展示。实时姿态、I/O 与碰撞均使用同一场景状态。

通电阶段增加接触辉光和局部照明，属于增强显示，不模拟激光束。阶段快照可查看通电状态；控制器暂停时实际模拟 DO 输出仍为 0。

极氪 001 采用参数化猎装外形参考，包括连续侧围、车门 / 后侧窗开口、天窗开口、冲压地板、前后舱和开放轮罩。比例参考 [极氪官方车型介绍](https://www.zeekrlife.com/global/vehicles/001) 及 [吉利首发车型资料](https://zgh.com/media-center/news/2021-04-15/?lang=en)；不是原厂 CAD，不代表某一量产年款的精确钣金、材料或焊点工艺。无轮胎、玻璃、内饰。示例焊点与回位路径已适配本教学几何。

新增验证：`tests/control-frames.test.mjs` 和 `tests/manual-scene.test.mjs` 覆盖坐标变换、IK / 接触互锁、六轴点动、模型切换及新车身完整周期采样。浏览器验证使用本机 Chrome / Playwright（本会话无 browser 插件），临时截图和脚本保存在 `/tmp/weld-final-*`。


## 紧凑布局与播放

所有场景默认以 2× 播放完整动作流程（含接近、焊接、保压、开枪和观察），只加快演示时钟，不修改工艺参数或节拍计算。电极特写慢放从 0.25× 调整到 0.5×。

三维视口自动填满可用高度；同屏控制台默认宽 360px，可拖动左侧分隔线调整并记住宽度（320–600px，随窗口限制上限）；分隔线支持左右方向键微调和双击还原。右上角折叠按钮释放整个工作区给 3D，点击画面“展开控制台”恢复，保留当前任务、关节姿态和播放状态。六轴点动采用紧凑行，说明与详细反馈默认收起。八步流程、节拍卡片及底部详情默认收起；点击底部标签可展开相应内容，再点当前标签或“收起”折叠。焊接结果示例、加工策略、分析预览也按需展开。详情以覆盖层展开，画面不缩小。

顶部项目名称是场景选择菜单，“工作站 / 焊接策略 / 仿真分析”合并在同一顶栏。原场景快捷行已删除；车身选择、全线 / 聚焦 / 特写和工位工具收纳到右侧“场景与工位”。打开控制台时同一组控件移入控制台；关闭后回到参数面板。工位选择与控制台任务、3D 观察同步。窄屏点动使用双列六轴布局；折叠控制台后 3D 恢复全高。展开额外说明或其他面板时，控制台仍可滚动。

## 发布到网站

GitHub Pages 直接提供仓库中的 `weld/weld.html`，不会自动编译 `src/`。修改后运行 `npm run build` 和 `npm test`，将源码、模型、依赖锁文件以及生成的 HTML / 许可证一并提交。`npm run check:build` 只校验、不改写文件；若发布文件落后于源码，测试及 GitHub Actions 检查会失败。

线上入口：<http://sophistudio.com/weld/weld.html>。顶部场景菜单支持“白车身 · ABB 三工位流水线”和“单机械臂焊接”，切换时保留当前会话内两套参数。
