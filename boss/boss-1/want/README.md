# Want 招聘工作台

位于 SophiStudio 根目录的 `want.html`，通过本机服务运行：

- 入口：http://127.0.0.1:8770/want.html
- 启动：双击根目录 `启动招聘工作台.command`，或运行 `python3 scripts/local-services.py install --only want`。
- 检查：打开 `http://127.0.0.1:8770/api/want/health`，应显示 `ok: true`。
- 手动启动：`node want/server.mjs`（默认端口 8770，已占用时不会终止其他进程）。
- 登录后台由 macOS LaunchAgent 保持运行；Mac 关机或休眠时不保证执行。

## 使用

人员资料库保留全部阅读记录，包括归档的 3D 打印岗位。可按岗位、分类、沟通状态、摘要/完整简历、日期、复核状态或关键词筛选；同名人员不会自动合并。统计卡支持今日、本轮与累计，按中国时区的实际阅读/发送时间计算。缺少稳定平台身份的资料按记录计数，不将同名复合键当作唯一身份。历史完整简历核查时间缺失时，不推算成今日核查。

打开“阅读 / 复核”可查看保存的职业资料、匹配依据、待核实项和消息正文。已发送且有核验记录的正文显示绿色；草稿或未核验内容不显示为成功发送。二次复核追加分类和说明，保留旧记录，也不增加新阅读人数。人工分类优先于模型建议；资料或职责改变后保留原分类，同时标记“资料更新后待复核”。

选择导出范围（当前筛选、勾选人员、全部资料）和 Excel/HTML/CSV 格式，再点击“导出”。Excel 包含人员分类、复核记录、消息记录、模型评估和导出说明。导出文件是新文件，原 `boss/人员沟通.xlsx` 不改写。CSV 使用 UTF-8 BOM 并防护公式执行；HTML 转义来源内容。

## Codex 后台评估

本机需要可用的 Node.js、Codex CLI，以及 `codex login` 的 ChatGPT 登录状态。程序仅检查 `codex login status`，不读取或展示登录凭据。点击“检查连接”更新状态。

按范围选择资料后，点击“Codex 评估”。任务按岗位分批（每批最多 20 条、单并发）调用 `codex exec`；只输入职业资料与岗位要求，不传姓名用于判断。固定参数关闭工具执行与浏览器操作，结果按 schema、记录 ID 和输入指纹检查后保存。缓存未过期时复用结果；原资料或职责改变时显示过期，保留人工分类。

评估消耗当前账号的 Codex 额度；不会自动切换到付费 API。额度或登录不可用时停止并显示原因。任务支持暂停、恢复，重启保留已完成批次，未完成部分标记中断。`WANT_CODEX_BIN`、`WANT_CODEX_MODEL` 和 `WANT_PYTHON` 可用于显式指定已安装的命令/模型；默认使用本机已有工具，无需新增 API Key。

当前版本的 Codex 能力是资料分类与复核辅助，不作录用或拒绝决定，也不自动改变沟通状态。

## BOSS 浏览器能力

当前没有独立后台 Edge 连接，工作台明确显示此状态。当前版本不采集新 BOSS 简历、不发送招聘消息、不处理登录验证；既有招聘自动化仍是独立流程。接入浏览器执行器前，必须统一原始数据写入、跨日去重、每日额度以及发送前记录/发送后核验协议，不能用模型结果替代实际送达记录。

## 文件与运维

- 输入只读：`boss/recruitment-data.json`、`boss/recruitment-config.json`。
- 新状态：`boss/want/state.json`，含复核、模型建议、队列与导出索引；排除 Git。
- 批次结果：`boss/want/jobs/`；新导出：`boss/want/exports/`；均只保存在本机。
- 日志：`~/Library/Logs/SophiStudio/want.log`。
- 后台配置：`~/Library/LaunchAgents/com.sophistudio.want.plist`。
- 状态使用独占锁和原子替换保存；有人工复核并发冲突时提示刷新，避免覆盖。
- 一个资料目录只允许一个评估服务持有任务锁，重复启动不会中断原任务。
- 从工作流卡片进入后，左上角 SophiStudio 返回原页面；直接打开时提示切回原标签页，避免把其他模块导向错误端口。
- 本机接口仅监听 127.0.0.1，校验 Host、Origin、请求令牌和请求体大小，不开放任意文件访问。

验证命令：`node --test tests/*.test.mjs`。XLSX 需已有 Python/openpyxl；默认优先采用 Codex 的本机运行环境。
