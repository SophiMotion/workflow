# 验证记录

## 设计核对

概念图：`design-concept.png`，1536×1024；实际界面：`desktop-preview.png`，同尺寸。使用内置浏览器检查交互与布局，独立 Chromium 验证真实下载和离线文件；内置浏览器未可靠返回下载事件，因此使用 Playwright 回退。`view_image` 检查概念及实装图片。

| 对比点 | 实际处理 |
|---|---|
| 页面布局 | 保留左预览/右参数的双栏布局，桌面购买按钮完整进入首屏；手机变为纵向布局，无横向溢出。 |
| 配色与卡片 | 冷白背景、白卡片、Google 蓝胶囊，红黄绿品牌点与步骤辅助色。 |
| 文案 | 保留标题、副标题、导航、三标签和购买 CTA；增加花边数量、下一步、本机保存状态等实际功能文字。 |
| 字体 | 标题采用系统宋体，输入和按钮用系统无衬线字体；未依赖在线字体。 |
| 模型素材 | 使用真实 Three.js 几何替代概念图的烘焙摄影。边缘与花纹更接近 CAD 模型；这是可编辑建模需求导致的明确差异，不声称照片级复刻。 |
| 控件 | 已修复大屏选中图标尺寸覆盖；数值输入和滑块同步，边界数值会归位。 |
| 图片和文字 | 真实轮廓、内孔、凸起高度参与预览与 JSON，未使用平面贴图冒充浮雕。 |

主页面保留概念的信息架构和视觉方向；几何造型及新增功能文案属于记录在案的差异，没有宣称像素级一致。
