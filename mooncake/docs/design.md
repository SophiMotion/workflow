# Mooncake 实现约定

目标：消费者通过 React + Three.js 定制月饼；管理员下载 JSON 或直接导入本机 Fusion；Fusion 插件从 JSON 生成可保存的实体，或打开同目录 HTML 设计后直接建模。

## 视觉

参考 `design-concept.png`（1536×1024）。冷白背景 #f8f9fc、白色卡片、深色文字 #202635、Google 蓝 #4285f4，红黄绿作为品牌辅助色。圆角卡片 24px，胶囊按钮，中文标题使用系统宋体，其他界面使用系统无衬线。桌面左 64% 为 3D 画布和三步提示，右 36% 为参数卡与购买按钮；手机顺序为标题、画布、参数、购买。保留图中导航、标题、CTA 和三标签结构。

交互：尺寸/正面/文字标签；数字与滑块同步；图片上传、反相和浮雕高度；文字最多两个汉字或五个英文字母，可留空；英文支持沿内圈排列；旋转、缩放、正面视图；浏览器本地草稿；管理员导出/导入；Fusion 内直传建模；购买弹窗选择数量并导出未付款的定制订单。管理员入口是离线工具模式，不构成账号鉴权。没有后端时不承诺提交或支付成功。

## 数据和建模

统一毫米单位，新导出 version=2，兼容 v1 直壁文件。参数包括底面直径、厚度、脱模斜度、周边样式、正面模式、花纹直径与浮雕高度、文字、字体、大小与排列。导出 `geometry` 包含基体上下截面闭合轮廓和浮雕多边形（外环、内孔、高度）。图片用本地 Canvas 灰度采样、3 级轮廓提取；文字也转轮廓以保持跨电脑字形一致。所有环不重复首点。Fusion 对数据类型、尺寸、顶点总数、轮廓边界和自相交进行校验，使用草图、基体放样和浮雕拉伸特征生成 BRep；图层先低后高与基体合并。不依赖远程字体、CDN 或图片服务。

HTML 打包内联脚本与样式，支持 file:// 及 Fusion Palette；源码位于 web，交付文件位于 mooncake，HTML 与 Python 同级。原始模板示例保留但不注册。

## 验证计划

测试几何边界、参数校验、孔洞面积、图片/文字轮廓、JSON 跨端校验、Fusion 错误清理；运行构建与 Python 语法检查；在浏览器核对桌面/手机、尺寸/花纹/图片/文字、导入导出、购买和离线加载。Fusion 实体生成需区分真实宿主验证与纯 Python/模拟 API 测试。

## 十款纹样与本机导入（v1.2）

正面使用十款独立参数纹样，卡片保持三列，可上下滚动；每款显示方向说明和 MakerWorld 灵感参考。原有三个 ID 保留。详细来源见 pattern-references.md。用户主按钮始终为“完成设计 · 去购买”；建模集中到管理员工具的“导入 Fusion”。

插件随 Fusion 启动，127.0.0.1:19876 仅接受本机可信网页。浏览器先取得会话令牌，再发送带唯一任务编号的设计 JSON；插件在自定义事件中建模，完成后自动将 F3D 与 JSON 保存在同目录 exports，并通过任务状态回传实际成功/失败。连接不存在时尝试 fusion360:// 唤起已安装应用。Fusion Palette 使用原生 adsk 通道。

确认后保存设计快照，建模期间仍可调整网页或购买；本次任务始终使用点击确认时的数据。一次仅处理一份任务，重复网络请求沿用任务编号。解除所有组件固定后再统一排布、捕获位置，并校验最终坐标，避免自动固定特征重算导致重叠。

## 多语言与刻字（v1.3）

页眉用独立语言菜单切换 zh/en/fr/ja。React Context 管理界面词条，localStorage 独立保存语言；切换不修改设计对象或重建几何。菜单、三步编辑、错误提示、购买和管理员/模具确认窗口均有翻译；Fusion 原生工具栏和原生错误详情沿用插件中文。

文字允许空、1–2 个汉字或 1–5 个 ASCII 英文字母，不接受混输。IME 组合输入结束后校验，非法草稿不覆盖上一次有效设计并禁用提交。`text.layout` 采用 straight/circular，旧文件缺省 straight。汉字始终整组居中；改回汉字后自动退出环排。

使用实际字形边界居中，并按内环可用半径缩放。英文环排从左到右顺时针沿圆弧，每字间隔 60°，最多覆盖 240°；每个字沿切线旋转。中心始终与月饼同心，不重新居中整个圆弧。所有笔画和字孔一起变换后保存，Fusion 直接使用轮廓并生成镜像阴模。

## 上小下大的脱模斜度（v1.4）

默认相对竖直方向 5°，可调 0–8°。顶面每个采样点沿径向内缩 `厚度 × tan(角度)`，底面保持标称直径及周边花边。三维预览逐一连接同序顶点，Fusion 用两个闭合截面放样；0° 保留直壁拉伸。花边采用径向截面的名义角度，非逐折面法向等角拔模。花纹直径不大于 `min(底径−10, 顶径−6)`，向下取到 0.1 mm；文字在内环自动适配。

模具成形段与月饼相同，上方改为小端等径通道；压片以小端轮廓减径向间隙生成，可从底部大端进出。上部等径通道避免继续收口后卡住压片。文字、图案的镜像凹纹和 M8 螺纹结构保留。

v2 的 draftAngle 和 topOutline 必填并跨端一致校验；旧 v1 必须为 0°，不能夹带非零斜度。自动保存的旧草稿迁移至默认 5°；手动导入旧文件保留原直壁形状。

## M20 硬件与 6 mm 腔底（v1.5）

根据确认尺寸固定硬件：腔底厚 6、光杆直径 30 长 40、M20 × 2.5 螺柱长 15、手柄及螺纹座直径 40（单位 mm）。螺纹座高 18、盲孔深 16，保留孔底 2 mm；套筒内高 = 月饼厚度 + 压片厚度 + 螺纹座高 + 1 mm 间隙，外高再加 6 mm 腔底。成形段保持原月饼高度与 5° 收口。

导入旧 M8 设计时统一升级硬件，保留间隙/侧壁/压片设置；月饼尺寸、文字和浮雕不改变。JSON v2 中明确记录所有固定硬件尺寸，拒绝不一致的值，旧插件会拒绝不认识的 M20 连接。网页确认显示实际尺寸，Fusion 文件属性及导出的 JSON 写入升级后的设置。

建模前检查 33 mm 完整顶出行程，以及 Ø40 螺纹座在小端内腔中的径向间隙；不满足时禁止导入并给出具体调整方向。前端与 Python 使用相同条件。螺纹参数对照本机 Fusion 的 ISOMetricprofile.xml：M20x2.5，内 6H / 外 6g，底孔 Ø17.5。

## Ø30 螺纹座与 6 mm 内部直壁段（v1.6）

对应用户测量截图：第一张 Ø40 的部位为压片背面螺纹座，外径改 Ø30；第二张 25 mm 的边为套筒成形段之后的内部直壁段，长度改为固定 6 mm。腔底厚度仍为 6 mm，套筒内高 = 月饼厚度 + 6，外高再加 6。

螺纹座直径现在与光杆相同，可沿默认 Ø30.6 导向孔滑动；不再需要在套筒内留出 18 mm 座高。压片 4–6 mm，可用完整顶出行程 = 光杆 40 + 座高 18 + 压片厚度 − 直壁 6 − 腔底 6，为 50–52 mm，因此全部设计厚度 10–40 mm 均可完整脱模。

旧 v1.5 数据（无 guideHeight，bossDiameter=40）升级到 Ø30/6；带新 guideHeight 却指定 Ø40 的不一致数据拒绝。较厚的旧压片仍能读入，但建模前要求调整至 4–6 mm，避免与腔底相撞。M20 盲孔 16 mm、螺柱 15 mm、手柄 Ø40 及月饼几何保持原设计。
