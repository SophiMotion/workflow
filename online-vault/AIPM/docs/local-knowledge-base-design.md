# AI 产品经理本地知识库：重建方案

状态：用户已批准继续，首版本地站点已实现。2026-09-23。

## 用户目标

将 Chrome 中可阅读的「两光年的 AI 产品经理知识库」重建为本机运行的 Web 知识库。源站不可下载，不要求用户先导出文件。只在本地保存与运行，不发布到互联网。

## 已核实的情况

- 已通过用户 Chrome 的已登录窗口读到首页与侧栏目录。
- 首页不是整个知识库；首页列出的章节链接常常指向同一个 PDF 内的不同主题，导入时必须按文档 URL 去重。
- 抽查「第一章 初识智能体.pdf」：共 18 页，下载按钮禁用，阅读器暴露了部分已加载页的文本层。未读取的页面不能视为已保存。
- 当前只能确认顶层栏目与部分章节链接，尚未遍历所有子目录，不能报告全库文章总数。
- 首页明确链接到 Datawhale Hello-Agents 的公开原始教材。已核实其 GitHub 仓库 LICENSE.txt 为 CC BY-NC-SA 4.0；后续仅在核对对应章节后收录并保留归属、许可和版本，不把原始教材版本假装为飞书 PDF 的逐字副本。

## 建议方案

采用本地静态知识库：左侧分类树，中间文章阅读，右侧文章目录；顶部搜索标题和已保存正文。风格沿用原库的白底、蓝紫色强调和中文文档排版，收窄宣传横幅，把阅读内容放在首屏。手机端将目录收进抽屉。

内容与页面分开维护：本地 Markdown/HTML 保存文档，JSON 保存标题、父目录、来源 URL、文档类型、读取时间、作者、许可证和收录状态。搜索索引只使用真实保存的文字。已存内容和站点资源不依赖 CDN 或飞书登录。

每个条目显示真实状态：

1. 已保存：正文和必要资源已保存且验证；断网可读。
2. 部分保存：仅部分页或正文已保存，明确缺失范围。
3. 公开原始版本：来自已核实的公开教材，与飞书版本分开说明。
4. 仅目录：有标题和来源链接，尚无本地正文。
5. 无法访问：记录实际错误，不伪造内容。

PDF、普通文档、表格、视频分别处理。PDF 文本层按页核对完整性；图表未保存时显示缺失说明。不能用缩略图代替全文。没有下载权限的附件保留来源入口，不修改权限或使用隐藏接口绕过限制。没有复用许可的第三方长篇内容保留目录、来源和简短阅读笔记。

## 备选方案与取舍

- 仅目录导航：最快，可本地搜索标题，但正文仍需联网打开飞书，不满足完全离线阅读。
- 本地内容与目录结合（推荐）：可逐步完整收录可保存资料，清楚显示缺失；首次交付需要逐项核验。
- 完整文件镜像：保真度最高，但需要源文件或相应导出权限，当前不能承诺完成全部原件镜像。

## 实施顺序

1. 遍历原侧栏与首页，保存真实目录和链接，去重并统计文档类型。
2. 核对公开原始教材，保存来源与许可；其他文章按可读取范围建立简短笔记或索引。
3. 实现本地阅读、全文搜索、面包屑、文章目录和移动端导航。
4. 检查本地链接、图片和搜索；以断网方式验证已保存条目。
5. 交付本地访问地址、启动入口、收录清单及缺失明细。

## 验收标准

- 实际收录数量从清单计算，分别报告正文、部分内容、公开原始版本、仅目录、失败条目。
- 已收录正文能打开、搜索、定位；目录链接指向真实存在的本地页面。
- 没有正文的条目不能展示编造的文章，也不能计入全文迁移数量。
- 桌面与手机宽度可阅读，键盘能够操作目录和搜索。
- 内容来源、许可证、版本差异与缺失情况在相应页面可见。
- 未读取浏览器凭据，未修改飞书文档、权限或下载设置。
