02 / 理解模型

先把关系说清楚。

目标表达“希望更好”，约束表达“必须满足”。距离和坡度单位不同，不能直接相加；需要尺度化并解释权重。模型必须写明假设，例如两条路线均无台阶。

J = α × 距离/500 + (1−α) × 坡度/10；可行条件：坡度 ≤ 任务上限。
03 / 算例与边界

一起检查这个例子。

教学数据A为320 m、4.8%，B为450 m、2.1%。α=0.7时，J_A=0.592，J_B=0.693，A成本更低；当任务坡度上限为3%时，A不可行，应选择B或补充方案。阈值是课堂设定，不是建设标准。

追问：哪些是假设？换一个条件，结论是否会改变？

04 / 动手实践

  3. 在交互图中调整距离权重和坡度上限。
  4. 分别解释“最优但不可行”和“可行集合为空”的情况。

05 / 判断与讨论

若α=0.3，且坡度上限为5%，哪条路线成本更低？

先独立判断，再与同伴比较证据。

展开教师参考

J_A=0.3×0.64+0.7×0.48=0.528；J_B=0.3×0.90+0.7×0.21=0.417，因此B更低。

06 / 检查与改进

怎样知道自己做对了？

改变一个约束后能重新求解，并解释结论为什么改变。

常见问题：为了得到想要的结论事后挑选权重；让CAD几何模型替代数学论证。

交付：变量表、假设清单、可复算的模型与方案选择记录。
