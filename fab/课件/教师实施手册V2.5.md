# Fab科技学习 · 教师实施手册 V2.5

2026-10-19。六类课程、12个核心单元。建议16周通用学习+4周项目深化；每单元基本教学节奏3×45分钟，需跨周复测与设备轮转。课程建议课时沿用学校安排，不将单元数直接等同于周数。

AI可协助生成与分析，学生须解释、检验并保留决策；教师按需要讲解概念、示范安全操作。正式参赛写作另遵当届规则。

# 从校园问题到测量任务

## 一、全景速览
| 项目 | 内容 |
|---|---|
| 课程分类 / 周次 | 场景与方案 / W1–2 |
| PBL任务 | 把“有点不方便”变成可观察、可验证的研究问题。 |
| Bloom重心 | 理解→应用→分析→评价；拓展任务进入创造 |
| CDIO位置 | 场景构思→设计→实现→测试，按当前单元往返迭代 |
| 目标 | 能写出对象、场景、现象和成功指标；能设计重复测量而非只拍一张照片。 |
| 核心产出 | 问题卡、采样计划、带单位的原始数据表。 |
| 材料条件 | 卷尺、秒表、记录表；校园观察按学校安排进行。 |

## 二、节奏与认知负荷
| 环节 | 建议时长 | 活动与产出 |
|---|---|---|
| 提出问题 | 10分钟 | 独立判断和问题记录 |
| 概念与算例 | 20分钟 | 样本均值 x̄ = (x₁ + x₂ + … + xₙ) / n；极差 R = 最大值 − 最小值。 |
| 预测与实验设计 | 15分钟 | 小组写出条件、预期和分工 |
| 原型或实验 | 45分钟 | 确定一项主指标及其单位，同一条件下至少重复测量3次。 |
| 验证与讨论 | 30分钟 | 与另一组互查单位和数据来源，收敛成可检验的问题。 |
| 反思与归档 | 15分钟 | 问题卡、采样计划、带单位的原始数据表。 |

高负荷分析后安排动手与同伴核对；加工等待时转入数据整理，不以设备速度决定学生评价。

## 三、教学法与分层
基础：用自己的话解释变量、单位、输入输出。应用：按步骤完成一次可复查记录。分析：比较条件变化与结果。评价：解释取舍与边界。拓展：设计一个能推翻原结论的新测试。

教师提问：追问：这个问题发生在谁身上？如果换一个时段，结论还会成立吗？先检查采样，再讨论工具。

## 四、技术白盒与算例
问题卡先写谁在什么时段遇到什么阻碍，再确定可记录的量。把路长、坡度、净宽与受阻次数分开，标明单位、仪器和时间。不要把个人感受直接写成全校结论。

同一段模型道路测得 12.1、12.3、12.2 m，均值12.2 m、极差0.2 m。它描述这三次测量的重复性，不等于整条校园道路的误差界限。

1. 在纸质校园图上标出观察点和受影响对象，写一张问题卡。
2. 确定一项主指标及其单位，同一条件下至少重复测量3次。
3. 保留原始值，记录天气、遮挡、工具或操作差异。
4. 与另一组互查单位和数据来源，收敛成可检验的问题。

## 五、产品表达与验收
其他组能凭你的记录重复一次测量，并知道数据适用于什么条件。

展示时包含问题、一次关键选择、证据和未解决条件；不以视频效果代替可复现数据。

## 六、教师注意事项
把一次观察当作规律；为了让结果更整齐而改写原始数据。

卷尺、秒表、记录表；校园观察按学校安排进行。 所有设备实操执行学校准入；不把教学仿真作为真实运行结论。

## 七、跨学科与评价检查
- [ ] 单位与关系能够解释；数学复杂度符合学生基础。
- [ ] 结构、电子与程序的任务边界清楚。
- [ ] 数据、版本与个人贡献对应。
- [ ] 验收依据是可观察的行为与产出。

## 八、练习、参考与课件
练习：两组同学分别在早高峰和午间测得不同通行时间，能否直接判断哪条路线更好？写出一个需要控制的条件。

教师参考：不能直接比较。时段、人流、起终点、行走方式等需可比；可在同一时段交替测两条路线并重复。

投屏课件：observe-课件.html；任务单：observe-任务单.md。
基础来源：https://sophigo.com/docs/courses/mobile-robot/high-school/1.html

2. 把一组实测尺寸标到简化平面图上，并标注未知区域。
3. 画出两个可实现方案，使用相同的距离、成本和限制条件。
4. 用一页方案说明记录选择与未解决的问题。

## 四、技术白盒与算例
目标表达“希望更好”，约束表达“必须满足”。距离和坡度单位不同，不能直接相加；需要尺度化并解释权重。模型必须写明假设，例如两条路线均无台阶。

教学数据A为320 m、4.8%，B为450 m、2.1%。α=0.7时，J_A=0.592，J_B=0.693，A成本更低；当任务坡度上限为3%时，A不可行，应选择B或补充方案。阈值是课堂设定，不是建设标准。

1. 列出变量、单位、来源及允许范围。
2. 写出目标函数和约束，说明为什么这样归一化。
3. 在交互图中调整距离权重和坡度上限。
4. 分别解释“最优但不可行”和“可行集合为空”的情况。

## 四、技术白盒与算例
模型的任务不是把已知数据解释得漂亮，而是对未使用的数据提出可以被检验的预测。先用简单模型；保留一部分新测量用于验证，比较改进是否超过测量波动。

v=0.8 m/s、τ=0.5 s、a=1.2 m/s²时，模型d≈0.667 m。若三次预测为0.50、0.70、0.90 m，实测为0.55、0.65、1.05 m，MAE≈0.083 m。恒定减速度只是简化假设。

1. 写下实验前预测，固定轮胎、地面和载荷条件。
2. 分别改变速度和时延，观察停止距离如何变化。
3. 在隔离模型场地进行低速实测，保留失败记录。
4. 比较预测、实测及基线；用误差决定是否修订模型。

教师提问：追问：现象发生在哪一层？能否用一个最小实验排除其中一个原因？

## 四、技术白盒与算例
